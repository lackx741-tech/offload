## Quick Start — Full Setup

### 1. Prerequisites
```bash
# Node.js
node --version  # should be 18+

# Python (if backend uses Python)
python3 --version  # should be 3.11+

# Foundry (for smart contracts)
foundryup       # or install from https://foundry.paradigm.xyz/
```

### 2. Install Everything
```bash
cd St3

# Install all dependencies
npm install
pip install -r requirements.txt  # if Python backend

```

### 3. Run Everything (in separate terminals)

**Terminal 1: Smart Contracts**
```bash
cd contracts
npm install
npx hardhat compile
npx hardhat node         # start local blockchain
```

**Terminal 2: Backend**
```bash
npm run dev              # or python3 main.py
# Runs on http://localhost:5000 or 8000
```

**Terminal 3: Frontend**
```bash
npm run dev
# Runs on http://localhost:3000
```

## .env Setup

### Root `.env` (project root)
```env
# Blockchain
PRIVATE_KEY=your_private_key_here
RPC_URL=http://localhost:8545                    # local anvil/hardhat
CHAIN_ID=31337                                   # local chain

# Contract Addresses (after deployment)
CONTRACT_ADDRESS=0x...                           # main contract

# Frontend
VITE_CONTRACT_ADDRESS=0x...
VITE_RPC_URL=http://localhost:8545

# Backend
DATABASE_URL=postgresql://user:pass@localhost/dbname
API_PORT=5000
DEBUG=true
```

### `contracts/.env` (if separate)
```env
PRIVATE_KEY=your_private_key_here
ETHERSCAN_API_KEY=your_key_here                 # for verification
RPC_URL=http://localhost:8545
```

### `frontend/.env` (if separate)
```env
VITE_CONTRACT_ADDRESS=0x...
VITE_RPC_URL=http://localhost:8545
VITE_API_URL=http://localhost:5000
```

## Common Commands

### Smart Contracts
```bash
cd contracts

# Development
forge build                      # Compile
forge test                       # Run tests
forge test -vvv                  # Verbose output
anvil                            # Start local blockchain

# Deployment
forge create src/Contract.sol --constructor-args ... --rpc-url http://localhost:8545 --private-key $PRIVATE_KEY

# Verification (mainnet)
forge verify-contract <address> src/Contract.sol --etherscan-api-key $ETHERSCAN_API_KEY
```

### Backend
```bash
npm run dev                      # Development server
npm run build                    # Build
npm run test                     # Tests
npm run seed                     # Seed database with data
```

### Frontend

## Deployment Order

1. **Deploy smart contracts** (local anvil or testnet)
   ```bash
   cd contracts && forge create src/Contract.sol ... && cd ..
   ```

2. **Start backend** (needs CONTRACT_ADDRESS from step 1)
   ```bash
   npm run backend:dev
   ```

3. **Start frontend** (needs VITE_CONTRACT_ADDRESS)
   ```bash
   npm run frontend:dev
   ```

## Troubleshooting

### Contracts won't compile
```bash
cd contracts
forge clean
forge install
forge build
```

### Local blockchain not connecting
- Check `anvil` is running in Terminal 1
- Verify RPC_URL in .env: `http://localhost:8545`
- Check CHAIN_ID: `31337` for local anvil

### Frontend can't see contracts
- Make sure CONTRACT_ADDRESS in .env is correct
- Redeploy contracts if you restarted anvil
- Restart frontend dev server after env changes

### Backend won't start
- Check DATABASE_URL is correct
- Make sure port 5000/8000 is free: `lsof -i :5000`
- Run migrations: `npm run db:migrate`
